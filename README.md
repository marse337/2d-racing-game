# 2D Racing Game

An arcade top-down racer built on a triangle grid, made with Godot.

**Play it in your browser:** https://marse337.github.io/2d-racing-game/

Controls: W/S or Up/Down to accelerate and brake, A/D or Left/Right to steer, Space to drift, R to restart, Esc for the menu. Gamepads work too.

Music streams in as you play (N shows what's playing, . skips). Your progress is saved in your browser.

This repository only contains the published web build.
